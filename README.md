# 🌐 Personal Portfolio Website – Keyu Chen

This repository contains the source code for my personal portfolio website, built with **React** and deployed using **GitHub Pages**.

The website highlights my background, professional experience, and technical projects in **Data Analytics, Financial Analysis, and Cloud Computing**.

🔗 Live Website: https://musucheng.github.io

---

## 📌 Features

- Responsive personal portfolio website
- Clean and modern UI (Cleanfolio-based)
- Light / Dark theme toggle
- Professional work experience section
- Custom navigation menu
- Project showcase with tech stacks
- Resume download
- Contact section
- Optimized for recruiters and hiring managers

---

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
- **Styling:** Custom CSS, Poppins Font
- **State Management:** React Context API
- **Deployment:** GitHub Pages (gh-pages)
- **Version Control:** Git & GitHub
