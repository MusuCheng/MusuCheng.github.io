# 🌐 Personal Portfolio Website – Keyu Chen

This repository contains the source code for my personal portfolio website, built with **React** and deployed using **GitHub Pages**.

The website highlights my background, professional experience, and technical projects in **Data Analytics, Financial Analysis, and Cloud Computing**.

🔗 Live Website: https://musucheng.github.io

---

## 📌 Features

- Responsive personal portfolio website
- Clean and modern UI (Cleanfolio-based)
- Light / Dark theme toggle
- Professional work experience section
- Custom navigation menu
- Project showcase with tech stacks
- Resume download
- Contact section
- Optimized for recruiters and hiring managers

---

## 🛠️ Tech Stack

- **Frontend:** React, JavaScript (ES6+), HTML5, CSS3
- **Styling:** Custom CSS, Poppins Font
- **State Management:** React Context API
- **Deployment:** GitHub Pages (gh-pages)
- **Version Control:** Git & GitHub

---

## 📂 Project Structure

musucheng_site/
│
├── public/ # Public assets

│ ├── components/ # React components

│ │

│ └── index.js # Entry point
│
├── build/ # Production build files
├── package.json
├── package-lock.json
└── README.md


The production build is deployed through the `gh-pages` branch.

## 🧩 Content Configuration

All personal information and project data are managed in:

src/portfolio.js


You can customize:

- Profile information
- Work experiences
- Projects
- Skills
- Resume link
- Social links

Example:

```js
const about = {
  name: 'Keyu Chen',
  role: 'Data Analyst | Financial Analyst',
  resume: 'KevinResume_FDA.pdf',
}
🚀 Local Development
Follow these steps to run the project locally.

1️⃣ Install Dependencies
npm install
2️⃣ Start Development Server
npm start
Then open:

http://localhost:3000
🌍 Deployment (GitHub Pages)
This project is deployed using gh-pages.

Build & Deploy
npm run build
npm run deploy
After deployment, the website will be available at:

https://musucheng.github.io
